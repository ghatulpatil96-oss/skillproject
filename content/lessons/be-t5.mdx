Express is the minimal backend framework most of the industry runs on. Routing, middleware, and error handling are its whole vocabulary.

## Routes by resource

```js
const jobs = express.Router();

jobs.get("/", listJobs);              // GET /jobs
jobs.post("/", requireAuth, createJob); // POST /jobs
jobs.get("/:id", getJob);             // GET /jobs/42
jobs.patch("/:id", requireAuth, updateJob);
jobs.delete("/:id", requireAdmin, deleteJob);

app.use("/jobs", jobs);
```

Handlers stay thin: parse input → call a service function → respond. Business logic lives in services you can test without HTTP.

## Middleware is just functions in a chain

```js
function requireAuth(req, res, next) {
  const user = getUserFromToken(req.headers.cookie);
  if (!user) return res.status(401).json({ error: "Unauthorized" });
  req.user = user;       // decorate for downstream handlers
  next();
}
```

Order matters: `cookie-parser` → auth → rate limit → routes → error handler.

## The error handler that saves you

Async errors don't reach Express's default handler — wrap them:

```js
const wrap = (fn) => (req, res, next) => fn(req, res, next).catch(next);

app.use((err, req, res, next) => {
  if (err instanceof ValidationError)
    return res.status(400).json({ errors: err.fields });
  console.error(err);
  res.status(500).json({ error: "Internal error" });
});
```
