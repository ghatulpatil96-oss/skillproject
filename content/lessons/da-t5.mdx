pandas is where analysts spend 80% of real project time: cleaning messy exports and reshaping them into answers.

## First contact with any DataFrame

```python
df.shape            # rows, cols
df.info()           # dtypes + missing counts — read this first
df.describe()       # distribution snapshot
df["region"].value_counts(dropna=False)  # categories incl. NaN
```

`info()` is the honesty check: dates stored as objects, numbers as strings, silent NaNs — all visible here.

## Missing data: judgment, not just fillna

```python
df.isna().sum()                    # how much is missing, per column

df["age"] = df["age"].fillna(df["age"].median())  # numeric: median
df = df.dropna(subset=["order_id"])               # keys: can't impute — drop
df["notes"] = df["notes"].fillna("")              # text: explicit empty
```

Each choice is a decision you should be able to defend in a review.

## Groupby: the SQL GROUP BY of Python

```python
df.groupby("region").agg(
    revenue=("amount", "sum"),
    orders=("order_id", "nunique"),
    avg_order=("amount", "mean"),
).sort_values("revenue", ascending=False)
```

## Reshaping: melt and pivot

Wide exports (one column per month) melt into tidy long form before analysis:

```python
tidy = wide.melt(id_vars="region", var_name="month", value_name="sales")
```
