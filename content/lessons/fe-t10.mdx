Effects connect React to the outside world — network, timers, subscriptions. Used well they're invisible; used badly they cause infinite loops and stale-data bugs.

## useEffect anatomy

```jsx
useEffect(() => {
  const ctrl = new AbortController();
  fetch(`/api/users/${id}`, { signal: ctrl.signal })
    .then(r => r.json())
    .then(setUser)
    .catch(e => { if (e.name !== "AbortError") setError(e); });
  return () => ctrl.abort();   // cleanup: cancel on unmount/re-run
}, [id]);                       // re-run only when id changes
```

Three questions for every effect: **when does it run** (deps), **how does it clean up** (return), **did I mean for this**?

## The effect you should delete

The React docs have a whole page on this because it's the #1 junior mistake — deriving state in effects causes extra renders and flicker:

```jsx
// ❌ effect + state for something computable
const [full, setFull] = useState("");
useEffect(() => setFull(`${first} ${last}`), [first, last]);

// ✅ just derive it during render
const full = `${first} ${last}`;
```

## Custom hooks: extracting logic

Any function starting with `use` can call other hooks — that's how duplicated logic becomes one reusable unit:

```jsx
function useLocalStorage(key, initial) {
  const [value, setValue] = useState(() => {
    try { return JSON.parse(localStorage.getItem(key)) ?? initial; }
    catch { return initial; }
  });
  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);
  return [value, setValue];
}
```

## useMemo/useCallback: measured, not vibes

Memoization has a cost. Reach for it when you've measured a problem (expensive computation, referential-identity-sensitive children) — not as decoration.

2. Refactor a component that syncs derived state with `useEffect` into plain derivation.
3. Build `useLocalStorage` and use it in your todo app — state survives refresh.

## Common mistakes interviewers spot

- Missing dependency arrays → runs every render
- Deleting deps to silence the linter → stale-closure bugs
- Effects that set state derived from other state (render loops)
