ES6+ turned JavaScript from a scripting language into an engineering language. Modules, classes, and modern syntax are table stakes in every professional codebase.

## Modules: import/export

```js
// math.js — named exports (many per file)
export function sum(a, b) { return a + b; }
export const PI = 3.14159;

// main.js
import { sum, PI } from "./math.js";

// only one default per file — the "main thing"
export default class Calculator {}
import Calculator from "./calculator.js";
```

## Destructuring & spread — daily bread

```js
const { name, ...rest } = user;        // pull + collect
const updated = { ...user, age: 21 };  // immutable update
const [first, , third] = places;       // skip with holes
```

## Optional chaining & nullish coalescing

```js
const city = user?.address?.city ?? "Unknown";
// user may be null → undefined instead of a crash
// ?? only falls back on null/undefined (0 and "" are kept!)
```

That `??` vs `||` difference (zero and empty string) is a favorite interview question.

## Map/Set vs plain objects

```js
const counts = new Map();       // any key type, iterable, .size
counts.set("js", (counts.get("js") ?? 0) + 1);

const seen = new Set(ids);      // O(1) membership checks
if (seen.has(id)) return;
```
